# 🧠 Дорожная Карта Развития Мозговых Возможностей: Genezis Cognitive Hyper-Brain

Документ описывает продвинутые мыслительные модули высшего уровня для наращивания «интеллектуальной мощности» нашего Ассоциативного ИИ.

---

## ⚡ 1. Двухпроцессная Модель Мышления (System 1 & System 2 Cognition)

Реализация модели психолога Даниэля Канемана для разделения мышления ИИ на два уровня:

```
                               ┌───────────────────────────┐
                               │     Входящая Ситуация     │
                               └─────────────┬─────────────┘
                                             │
                       ┌─────────────────────┴─────────────────────┐
                       ▼                                           ▼
         ┌───────────────────────────┐               ┌───────────────────────────┐
         │ SYSTEM 1: Быстрое Чутье   │               │ SYSTEM 2: Глубокий Анализ │
         │ (При уверенности > 0.3)   │               │ (При уверенности < 0.2)   │
         │ - Косинусный поиск <1мс   │               │ - 10-шаговые волны во сне │
         │ - Мгновенная реакция      │               │ - Симуляции альтернатив   │
         └───────────────────────────┘               └───────────────────────────┘
```

- **System 1 (Быстрое Мышление):** Мгновенная ассоциативная реакция за $<1$ мс на основе косинусного матричного поиска в знакомых рутинных ситуациях.
- **System 2 (Глубокий Анализ и Размышление):** Когда порог уверенности ниже `0.2` (сложная/незнакомая ситуация), ИИ делает физическую «паузу на размышление», запускает волновое моделирование будущего на 10 шагов вперед по графу памяти и разворачивает визионерские симуляции во мнении.

---

## 🎯 2. Эвристическая Интуиция на баще Яркости Впечатлений (`IntuitiveSalience`)

- **Яркость Опыта (`Salience Score`):** События с экстремальными скачками наград ($|\Delta R| \gg 0$, сильная боль от уронa или колоссальный профит) получают приоритетные яркие метки.
- При появлении хотя бы отдаленно похожей ситуации ИИ делает **интуитивный прыжок памяти** к этому сильному впечатлению, минуя рутинные нейроны.

---

## 🌐 3. Семантическая Сеть Концептов (`SemanticConceptNetwork`)

- Автоматическое объединение связанных нейронов в **высшие смысловые категории**:
  * Категория «Защитный Манёвр»
  * Категория «Агрессивный Штурм»
  * Категория «Экономия Ресурсов»
- Мозг начинает мыслить не отдельными координатами, а **смысловыми категориями**.

---

## 🔀 4. Многомодальный Гипер-Граф (`MultiModalAssociativeBridge`)

- Способность одновременно связывать в одном нейроне:
  1. Числовой вектор состояния.
  2. Временно́й тренд показателей.
  3. Текстовый интент / команду.
  4. Графический кадр/маску.
