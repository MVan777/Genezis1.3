# 🚀 Дорожная Карта Продукта: Genezis AI Commercial SDK & Enterprise Server

Документ описывает стратегический продуктовый план трансформации ассоциативного ИИ **Genezis 3.0 Ultimate Engine** в законченный **коммерческий продукт (SDK и API Сервер)** для бесшовной интеграции в любые проекты (Telegram-боты, маркетплейсы, трейдинг-платформы, веб-сервисы, мобильные приложения и игры).

---

## 📊 1. Текущий Статус (Технологический Фундамент)

На текущий момент в проекте **Genezis1.3** реализовано и верифицировано мощное универсальное ядро:
- **`Genezis3UltimateEngine`:** Стандартизированный API (`act` / `learn`), принимающий любые векторы наблюдений $O \in \mathbb{R}^D$.
- **3-Уровневая Иерархия Абстракций:** Автоматическая группировка опыта (*Сырые ситуации ➔ Тактические маневры ➔ Стратегические Золотые Прототипы*).
- **5-Шаговое Волновое Моделирование Памяти (`DeepMentalGraphSimulator`):** Прогнозирование будущего по связям графа $N_{t-1} \to N_t$ за 5 шагов до решения.
- **Ретроспективные Сны и Уроки (`analyze_and_simulate`):** Автоматическое выявление ошибок и генерация нейронов-уроков во сне.
- **Комбо-Цепочки (`StrategicSequenceChainer`):** Исполнение комплексных маневров из 3-5 шагов.
- **Мета-Адаптация и Любопытство:** Автоматическое подстраивание порогов уверенности и параметров в незнакомых средах.

```
                                     │
         Любая среда (Tg_bot_market, Web SaaS, Трейдинг, Игры, CRM)
```

---

### 📦 Модуль A: `GenezisSDK` (Обертка-Библиотека)
Удобное подключение ИИ к любому Python-проекту в 3 строчки кода:
```python
from genezis import AssociativeBrain

# Загрузка или создание ассоциативного мозга
brain = AssociativeBrain.load_or_create("tg_market_brain.pkl")

# ИИ принимает решение на основе вектора
action = brain.decide(user_features)

# Передача обратной связи/награды
brain.feedback(reward=1.0)
```

---

### 🌐 Модуль B: REST API & WebSockets Сервер (`genezis-server`)
Легковесный сервер на FastAPI / WebSockets для подключения нашего Ассоциативного ИИ из **любого языка программирования** (JavaScript / Node.js, C#, C++, Go, PHP, Swift, Kotlin):
- `POST /api/v1/decide` ➔ Принять вектор ситуации и вернуть решение ИИ.
- `POST /api/v1/feedback` ➔ Передать подкрепление (награду/штраф) и обучить ИИ.
- `GET /api/v1/stats` ➔ Получить статистику нейронного графа в JSON.

---

### 🔀 Модуль C: Универсальный Векторизатор (`DataEmbedder`)
Автоматический конвертер для превращения сырых нечисловых данных в нормализованные $N$-мерные векторы ситуации:
- **Текст / Сообщения Telegram-ботов:** Конвертация слов/интентов в векторов ситуаций.
- **JSON / Данные пользователей:** Преобразование профилей и истории действий в числа.
- **Таблицы / Финансы:** Автоматическая нормализация численных показателей.

---

### 🖥️ Модуль D: Веб-Панель Мониторинга (Web Dashboard UI)
Современный веб-интерфейс на HTML/JS/CSS для наблюдения за работой ассоциативного мозга прямо в браузере в реальном времени:
- Визуализация графа нейронов и бирюзовых временных связей без привязки к Pygame.
- Мониторинг динамики уверенности (`confidence`), снов и уроков 24/7.
- Панель ручной подстройки параметров любопытства и сохранения дампов памяти.
